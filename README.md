# OmicsRefinery

<img src="man/figures/logo.png"
     align="right"
     height="160"
     alt="OmicsRefinery package logo" />

`OmicsRefinery` is an R package for preprocessing proteomics and metabolomics data
for downstream multi-omics analysis.

It currently provides two main workflows:

- `refineProteomics()` for precursor-to-protein preprocessing
- `refineMetabolomics()` for peak-to-metabolite preprocessing

The package supports:

- missing-value handling and imputation
- MNAR or MAR classification for mixed imputation
- normalisation and optional transformation
- optional batch-wise imputation and ComBat batch correction
- feature aggregation and QC plotting

## Requirements

R >= 4.0 and Bioconductor >= 3.19. `QFeatures` should be minimum v1.14.0: earlier
releases named the abundance-column argument of `readSummarizedExperiment()` `ecol`
rather than `quantCols` and will cause package failure. Development
and testing are done on R 4.4.1 with Bioconductor 3.20.

## Installation

```r
if (!requireNamespace("BiocManager", quietly = TRUE)) install.packages("BiocManager")
if (!requireNamespace("remotes", quietly = TRUE)) install.packages("remotes")

# Core dependencies.
BiocManager::install(
  c("limma", "MsCoreUtils", "QFeatures", "SummarizedExperiment", "sva", "vsn"),
  ask = FALSE)

# Optional imputation and normalisation engines. MsCoreUtils only suggests these,
# so they are not installed automatically -- but "mixed", the default for
# refineMetabolomics(), needs missForest and imputeLCMD.
BiocManager::install(
  c("missForest", "imputeLCMD", "impute", "norm", "pcaMethods", "preprocessCore"),
  ask = FALSE)

remotes::install_github(
  "bradleyalexward/OmicsRefinery",
  dependencies = NA)
```

### Which optional packages does each method need?

| Option | Needs |
|---|---|
| `impute_method = "mixed"` | missForest **and** imputeLCMD |
| `impute_method = "RF"` | missForest |
| `impute_method = "QRILC"`, `"MinDet"`, `"MinProb"` | imputeLCMD |
| `impute_method = "knn"` | impute |
| `impute_method = "bpca"` | pcaMethods |
| `impute_method = "MLE"` | norm |
| `normalisation_method = "quantiles"`, `"quantiles.robust"` | preprocessCore |

Both functions check for these before doing any work and report the exact install
command if one is absent.

## Example data

`inst/extdata/` holds a small **synthetic** example dataset: four metabolomics peak
tables, three proteomics fractions, and a sample metadata table covering 30 samples.

Every value was generated by `data-raw/make-example-data.R`. The files contain no real
measurements and no human subject data; their column names and layout imitate a cleaned
Progenesis QI peak table and a wide precursor table so the worked examples look like
real input. Regenerate them with:

```r
Rscript data-raw/make-example-data.R
```

See `vignette("using-the-example-omics-data")` for a full worked run of both workflows.

## A note on the missingness classifier

With `impute_method = "mixed"`, each feature is tested for whether its *detection*
pattern is explained by the covariates named in `mnar_variables`, using a
likelihood-ratio test with one Benjamini-Hochberg correction across features.

This detects association with metadata you measured. It is a practical heuristic for
routing features to left-censored (QRILC) imputation, not a proof of the formal
missing-not-at-random mechanism, which depends on values that were never observed.

## Repository layout

- `R/` contains the package functions; `R/utils.R` holds the internal helpers shared
  by both workflows
- `tests/testthat/` contains package tests
- `inst/extdata/` contains the synthetic example input files
- `data-raw/` contains the script that generates them
- `.github/workflows/` runs `R CMD check` on every push
